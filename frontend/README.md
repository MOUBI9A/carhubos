# Fider Frontend (Next.js 16)

Frontend app for Fider public pages and role-based dashboards.

- Default URL: `http://localhost:3002`
- Stack: Next.js 16 + React 19 + Tailwind

## Run locally

```bash
cd /home/runner/work/carhubos/carhubos/frontend
npm install
npm run dev
```

## Validate

```bash
cd /home/runner/work/carhubos/carhubos/frontend
npm run lint
npm run build
npm run test
```
