## 1. What the product is

Multi-tenant **SaaS ERP for car-rental agencies in Morocco**. Public brand **"Fider"** — *"the trust layer for mobility"*. Locale defaults: currency **MAD**, **20% VAT (inclusive)**, identity docs **CIN / passport**, comms via **WhatsApp (Twilio)**.

Three tiers of user:
- **Founder** (`ROOT_ADMIN`) runs the platform (`/admin`).
- **Agencies** — paying tenants: `OWNER`, `MANAGER`, `AGENT` (`/dashboard`, `/agent`).
- **Renters** (`RENTER`) — end users with a self-scoped portal (`/portal`).

Status: **demo → market-ready**, Phases 0–8 + 11 + 12 done. Remaining: Phase 9 (deploy — human gate), Phase 10 (final review), plus small follow-ups.

## 7. Invariants — violating any of these is a bug, not a style choice

1. **Tenant isolation.** Every business query is scoped `where: { …, agencyId }`. `agencyId` comes from `@CurrentUser()` (the JWT) — **never** from the request body. A cross-tenant read/write returns **404** (`NotFoundException`), not 403 — don't leak existence.
2. **Roles.** Put `@UseGuards(AuthGuard, RolesGuard)` at class level and decorate only the restricted handlers (`RolesGuard` returns `true` when a handler has no `@Roles`). Public `POST /auth/register` may self-assign only `OWNER/AGENT/RENTER` and may **never** accept an `agencyId`.
3. **Money = `Decimal`.** Prisma returns `Prisma.Decimal` (Decimal.js), **not** `number`. Use `.plus/.minus/.times/.equals/.gte/.toDecimalPlaces(2)` — never `+ - * /`, `Math.round`, or `>`/`<` on a Decimal, never string-interpolate one into math. **Compare in integer cents.** The global `DecimalToNumberInterceptor` converts Decimals → JS numbers in JSON responses, so the **wire contract stays numeric** and the frontend correctly expects `number`. Non-money floats (`Car.currentRoi`, `RenterIdentity.globalScore`) stay `Float`. *(This rule has been broken twice — most recently MRR/ARR, fixed in `e9e32d0`. Assume it's the easiest mistake to make in this codebase.)*
4. **Transactions for check-then-act.** Booking-overlap re-checks and money reconciliation run inside `prisma.$transaction`, using the **`tx`** client for the guard read (not `this.prisma`). Throw inside the callback to abort atomically.
5. **Validation.** DTOs with `class-validator`; constrain enum-like strings with `@IsIn([...])`. The global pipe strips (`whitelist`) and rejects (`forbidNonWhitelisted`) unknown props, and `transform: true` is on.
6. **Audit.** Sensitive actions write an `AuditLog` via the `@Global` `AuditLogsService`: `log(agencyId, actorId, action, entityType, entityId, before?, after?)`.
7. **Rate limiting.** `ThrottlerGuard` is global (100/60s); auth routes are `@Throttle({ default: { limit: 5, ttl: 60000 } })`. It caps request *rate*, not response *size* — unbounded list endpoints still need a `take`.
8. **Emails are normalized** (trimmed + lowercased) at all four `User`-creating entry points: `LoginDto`, `RegisterDto`, `ProvisionTenantDto`, `CreateStaffDto`. `common/identity-email-normalization.spec.ts` is table-driven over all four — **add any new entry point to that test.**
9. **Honesty.** No fake-success toasts, no invented capability claims in UI copy, no auto-charge that fabricates an amount — flag for manual review when there's no real cost signal.

## 8. Known gotchas

- Prisma `Decimal` serializes to a JSON **string** — that's why the interceptor exists. New endpoints returning money get it for free (plain objects/arrays only; PDF Buffers/streams pass through).
- Money math on `Float` drifts (`333.33 × 3 ≠ 999.99`). Always Decimal cents.
- `docker compose` interpolates **all** services, so the `backend` service's `${JWT_SECRET:?}` must resolve even when you only `up -d db`.
- The repo lives under `~/Desktop` = **Google-Drive-synced** → `mtime` is not a trustworthy change signal. Diff, don't trust timestamps.
- Frontend E2E files are `*.e2e.ts` specifically so vitest (which globs `*.spec.ts` / `*.test.ts`) skips them. Keep that naming.
- Booking date inputs are native `required`, so an empty submit triggers *browser* validation, not our JS toast — to test the JS guard, fill dates and leave the comboboxes empty.
