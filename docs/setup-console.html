Three clicks outside this repo

Each of these lives in a dashboard only you can sign into. Two of them are currently blocking something real.

Stripe → set a business name blocking checkout

dashboard.stripe.com/account → Account details → business name. Stripe refuses to create any Checkout session until an account has one, so this blocks online payment entirely — for every agency, in test mode and live mode alike.

Confirmed live, 11 Aug. Your restricted test key authenticates correctly; the request fails on this rule and nothing else. Once the name is set, the whole checkout path is testable with what you already have configured — no new keys.

Twilio → apply for a WhatsApp sender silently undelivered

The configured number is Twilio's shared public sandbox. It only delivers to people who separately opted into that sandbox first, so no customer will ever receive a notification from it — and nothing errors to tell you that.

Lead time. Meta's approval takes days to weeks, so it's worth starting well before you need it rather than during launch week.

GitHub → require the CI checks your call

Settings → Branches → protect main → require the Backend, Frontend, Backend E2E and E2E checks. Until then a red build can still be merged, which makes the whole test suite advisory. Repo-admin only — I have no way to set it. Worth doing after the open pull requests land, or it blocks each of them until it's rebased.
